# Trampas en tu código

Charla para el **OWASP Village de Ekoparty 2026** sobre ciberengaño aplicado al OWASP Top 10.

Los logs registran todo y casi nada de lo que registran es una señal clara. Esta charla propone el camino inverso: sembrar dentro de la propia aplicación rutas, IDs, filas y cuentas que ningún usuario legítimo toca nunca. Si alguien los toca, no hay lectura inocente posible, y ese evento es una alerta de alta fidelidad desde el origen.

A lo largo de la charla se recorren A01, A05, A07 y A09 con ejemplos de código y dos demos sintéticas, y se cierra con los límites del engaño y una forma concreta de empezar.
